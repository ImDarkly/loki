## Owner-authorized correction pass

Scope: same branch; only striping/winding, box-only ship silhouette, visible flat plaza and creature-water markers, exported ship/lantern dimensions, debug camera/HUD readability, and confirmation of all eight rings. No fish-tug or zone-fixture changes. No art, fog changes, glow, highlights, rocks, arch, ladder traversal, or new gameplay. #348's acceptance criteria do not require shoreline rocks or an arch.

Striping diagnosis was shown before source changes. An isolated single box generated through the production `_layout_box` helper reproduces the stripes with no duplicate or coplanar geometry. Two runs measured adjacent-pixel variation 0.00771. Single-variable probes: shadows off 0.000010; backface culling disabled 0.00771; normal bias 1.0 with shadows on 0.000343; normal bias 2.0 with shadows on 0.000010. The cause is self-shadowing at the existing normal bias 0.1. Apply the measured bias 2.0 while keeping shadows and fog enabled. Ground winding is a separate correction; keep backface culling enabled.
